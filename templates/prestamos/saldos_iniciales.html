¿Qué es un saldo inicial?

Utilice esta opción cuando el sistema comienza a funcionar y ya existen préstamos pendientes cuyo historial no se encuentra registrado.

Ejemplo
Acción 38
S/ 17,207.00

Al registrar este importe, el sistema lo considerará como saldo de préstamo de apertura. Las amortizaciones posteriores podrán afectar este saldo.
